# SORA — Sushi & Pizza · QR-меню

Демонстрационное QR-меню ресторана (React + Vite + Tailwind + Framer Motion).
Весь интерфейс на русском языке, валюта — тенге (₸). Блюда и цены вымышленные.

## Запуск

```bash
npm install
npm run dev     # режим разработки
npm run build   # production-сборка в папку dist/
```

## Где что менять

| Что | Где |
|---|---|
| Блюда, описания, цены, категории | `src/data/menu.js` |
| Фото блюд | `public/images/` (имя файла указывается в поле `image`) |
| Номер WhatsApp для заказов | `ORDER_CONFIG.whatsappNumber` в `src/data/menu.js` |
| Цвета | `tailwind.config.js` |
| Текст героя | `src/components/Hero.jsx` |

### Замена фотографий
1. Положите фото (желательно `.webp` или `.jpg`, около 1200×900 px) в `public/images/`.
2. В `src/data/menu.js` поменяйте поле `image`, например:
   `image: '/images/margherita.webp'`.
3. Компоненты менять не нужно. Если файл не найден, вместо него показывается `placeholder.svg`.

Фото в комплекте — векторные иллюстрации блюд (SVG), созданные для демо, чтобы сайт выглядел оформленным сразу после запуска.
Для реального проекта замените их на фотографии своих блюд (или на изображения с лицензией, разрешающей коммерческое использование), сохранив те же имена файлов или обновив поля `image` в `src/data/menu.js`.

## Заказы

Пока `whatsappNumber` пустой, кнопка «Оформить заказ» показывает сводку и уведомление
о демонстрационной версии. Когда номер будет указан, заказ откроется в WhatsApp с текстом заказа.

## QR-код

QR-код генерируется из адреса текущего сайта (`window.location.origin`).
Кнопка «Скачать QR-код» сохраняет PNG 1200×1200 px для печати.
Для публичного использования сначала опубликуйте сайт (например, Vercel, Netlify или GitHub Pages),
затем откройте страницу по реальному адресу и скачайте QR-код.
